# 申论训练助手 v0.1.6

## 这是什么软件

申论训练助手是一款本地优先的申论训练工作台：题库、材料阅读、草稿、训练记录和批改快照保存在本机，适合把“独立作答—提交批改—错题复盘”串成持续训练闭环。

主要功能包括：

- 近年公开申论整卷发现、结构校验和题目导入；
- 材料阅读、高亮/下划线/批注和来源追溯；
- 概括归纳、提出对策、综合分析、贯彻执行等题型训练；
- 大作文独立五步短练、整篇作答和五维度批改；
- 草稿自动保存、进行中答题、训练记录和错题复盘；
- 可选的远程 AI 批改，模型凭据保存在操作系统凭据库。

## 本次更新

- 修复公开题库导入后“来源显示已入库，但题库页没有同步”的问题。设置页完成初始化、批量导入或手动导入后，会立即刷新主题库。
- 修复桌面版 SQLite 打开失败时静默切换到空 localStorage、造成题库和记录像被清空的问题。现在会显示数据保护页面并停止加载。
- 正式版和 Preview 明确显示运行身份；两者使用独立数据目录，避免误把 Preview 当成正式版。
- 自动更新安装前执行 WAL checkpoint，并备份数据库及 sidecar 文件；备份失败时不会继续更新。
- 版本号更新为 `0.1.6`。

## 数据安全提醒

升级或安装前请不要卸载应用、清空应用数据或删除数据库目录。正式版数据目录为：

`%APPDATA%\\com.shenlun.trainer`

本版本不删除已有题库、草稿、训练记录或批改快照。公开来源列表中的“失败/阻断”表示网页结构暂未通过自动解析，不等于已经导入的题目丢失。
