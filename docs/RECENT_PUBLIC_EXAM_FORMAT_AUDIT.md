# 最近10年公开申论卷面格式审计

> 目的：记录 V0.1 结构化导入器实际核对过的公开页面格式族。只保存来源 URL 与结构观察，不在仓库复制第三方整卷全文。

当前产品窗口为滚动最近 10 个自然年。以 2026 年为例：2017—2026。

当前 parser 审计契约：`public-exam-audit@0.2.0`；批处理状态契约：`public-exam-batch@0.2.0`。parser 规则发生会影响结构判断的变化时，应同步升级这些版本，使旧审计/失败缓存重新进入校验，而不是永久沿用旧结论。

## 2. 当前 parser 明确支持的近10年格式族

### A. 标准题号

- `一、` / `二、`
- `第一题：` / `第二题：`
- `（一）题干……（N分）`

### B. 材料标题

- `材料1`
- `材料1：`
- `材料1(站内编号)`

### C. 无题号连续作答要求

用于 2018/2019 江苏等真实卷面：

- 顶层没有“一、二、三”；
- 每道题干本身有明确 `（N分）`；
- 每题后紧跟 `要求：`；
- 只有在至少两道题都满足该结构时才启用 fallback；
- 出现疑似数字小问/嵌套计分结构时不使用该 fallback。

### D. 字数表达

当前覆盖：

- `不超过 N 字`
- `不多于 N 字`
- `N 字以内`
- `篇幅 N 字左右`
- `N—M 字` / `N-M 字`
- 多行 `要求：（1）……（3）不超过 N 字`

只有“至少 N 字 / 不少于 N 字”而没有可靠上限时，不把最低字数伪装成上限，自动导入应阻断。

### E. 材料引用

当前覆盖：

- `给定资料1`
- `给定材料2`
- `资料 7`
- `材料3`
- `给定资料3～5`：展开为 `[3,4,5]`
- `给定 资 料 4`：先做字间空格噪声归一化，再识别为材料4
- `给　定　材　料 4`：兼容全角空格

材料引用兼容只修复明确排版噪声；不能识别材料号时仍 fail closed，不猜测。

### F. 题型关键词补充

近10年真实卷面中需要特别识别：

- `写一则短评` → 贯彻执行
- `写一封感谢信` → 贯彻执行
- `发言 / 发言稿` → 贯彻执行
- `草拟…工作指南 / 指南` → 贯彻执行
- `对此谈谈你的看法 / 你怎么看` → 综合分析
- `分别指的是什么，并说明…如何协同发挥作用` → 综合分析
- 普通“概括/说明如何通过某些做法实现某结果”不因单独出现“如何”就自动升级为综合分析
- `议论性文章 / 议论文 / 写一篇文章` → 文章写作

## 3. 2025 国考副省级固定结构预期

来源：`https://gwy.gkzhenti.cn/paper/1743902341589`

| 题号 | 分值 | 字数上限 | 材料范围 | 题型 |
| --- | ---: | ---: | --- | --- |
| 1 | 15 | 350 | 材料1 | 综合分析 |
| 2 | 10 | 300 | 材料2 | 综合分析 |
| 3 | 20 | 400 | 材料3 | 贯彻执行 |
| 4 | 20 | 400 | 材料4 | 提出对策 |
| 5 | 35 | 1200 | 整卷4则材料 | 文章写作 |

这套卷作为首个真实端到端验收锚点。若后续 parser 改动导致上述结构发生变化，必须先核对公开页面，再决定是来源变化还是 parser regression。

## 4. 明确不自动处理的结构

下列结构在没有专用模型前必须 fail closed：

- 一道大题下面再含多个独立计分小问；
- 无法识别分值；
- 无法识别可靠字数上限；
- 非作文题完全无法识别材料引用；
- 页面正文混入答案解析且无法可靠分离；
- 最近10年窗口之外的历史卷。

## 5. 维护原则

1. 只为 2017—2026（随后按自然年滚动）的真实格式投入主开发资源。
2. 新增 parser 规则前必须找到近10年公开页面实例或明确测试 fixture。
3. 影响 parser 判定/批处理恢复语义的规则变化必须升级审计/批处理状态版本，使旧缓存失效并重新校验。
4. 扩大覆盖率不能以降低 fail-closed 门槛为代价。
5. 主来源解析失败时允许人工核验/后续 adapter，不静默写入错误题库。
6. 公开页面答案不是 Human Gold；该文档只审计题目/材料结构。
