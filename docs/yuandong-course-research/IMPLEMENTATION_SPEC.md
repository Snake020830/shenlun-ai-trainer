# 大作文训练与独立批改实现规范

## 目标与边界

文章写作不进入小题的“材料候选点—评分点—逐点映射”流程。系统只共享题目、作答、模型传输和历史快照等基础设施，审题、评分合同、提示词、结构校验、结果呈现和版本号均独立。

课程资料属于写作教学证据，不是官方阅卷细则。因此产品统一使用“课程证据支持的诊断分”表述；未经作文 Human Gold 样本校准，不显示“官方等值分”或类似承诺。

## 训练链

| 阶段 | 训练动作 | 课程依据 |
| --- | --- | --- |
| 1. 审题立意 | 提取题干关键词，判断单/双/多主题，形成标题和总论点 | YD-THEME-01、YD-THESIS-02 |
| 2. 分论点 | 按题干、题干所在材料、全篇材料/客观小题的顺序找角度并挂接证据 | YD-SUBPOINT-03、YD-STRUCTURE-04 |
| 3. 主体论证 | 分论点—分析—事例—评论—回扣 | YD-ARGUMENT-06 |
| 4. 素材转化 | 将案例整理为主体—做法—结果，抽象机制并绑定分论点 | YD-EVIDENCE-07 |
| 5. 结尾收束 | 回扣总论点、照应分论点、完成展望/号召 | YD-CLOSING-08 |

短练每个阶段只保留一个核心输入（审题立意阶段另含自拟标题）。单步按钮仅做快速结构检查；五步全部完成后，通过独立短练批改合同把“标题—总论点—分论点—主体论证—素材转化—结尾”作为一条连续写作链进行整体诊断。整体报告必须逐步给出用户原文证据、课程规则编号、问题原因、最优先修改动作和本步改写示例，并另外报告主线断点、修改优先级和整篇组装计划。启用并通过自检的远程模型负责材料语义核对和论据证明力判断；本地模式只提供明确标注的结构兜底，不冒充语义批改。短练结果不计入整篇作文分数，整篇作答仍使用独立五维量表进行正式作文诊断。

## 独立诊断量表

内部量表先按 100 分诊断，再按题目实际分值等比例折算：

| 维度 | 内部权重 | 核心判断 |
| --- | ---: | --- |
| 立意与总论点 | 30 | 主题词、主题关系、标题—总论点一致性 |
| 结构与分论点 | 20 | 开头—主体—结尾完整性、分论点同层且不重复 |
| 论证链条 | 25 | 分析、事例、评论与回扣是否真正证明观点 |
| 材料转化 | 15 | 材料是否被转化为同领域、可证明的论据 |
| 语言与字数 | 10 | 准确、连贯、重复控制、字数合规 |

权重是产品内部训练量表，不声称来自官方赋分表。每个维度必须输出：得分、答案原文证据、诊断、一个最优先修改动作和课程规则编号。

## 两阶段模型流程

1. **审题建构**：模型不得读取考生答案，只根据题干和材料输出主题类型、关键词、建议总论点、2—4 个分论点候选及其来源证据。
2. **文章诊断**：输入第一阶段结果和考生全文，识别标题、总论点、分论点、段落与首尾，完成五维评分并生成重写提纲；不生成整篇模板范文。

两个阶段都有严格 JSON schema、应用侧校验和一次修复重试。缺维度、重复维度、越界分数、未知课程规则、空证据均拒绝进入历史记录。
