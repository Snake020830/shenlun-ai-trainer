# 袁东老师大作文课程核心方法提炼

## 一句话结论

这套课的主线不是堆积“万能模板”，而是把大作文还原为一条可执行流程：**先用题干关键词锁定主题和总论点，再按材料证据寻找分论点，最后用可组合的论证要素完成段落。** 课程把“不跑题”置于文采之前，把模板定位为防止考场空白的脚手架。

本提炼依据 344 页讲义和去重后的 21 个字幕内容单元。直播暖场、歌曲、招生话术、私人故事和未经材料验证的成绩宣传均未纳入方法结论。

## 一、整篇文章的基本骨架

常见 1000 字文章按五段组织：

1. 开头：引出并落定总论点。
2. 分论点一：约 200 字。
3. 分论点二：约 200 字。
4. 分论点三：约 200 字。
5. 结尾：回扣总论点、分论点并收束。

1200 字题目可以根据材料层次写四个分论点，但不能为了凑段数制造重复观点。课程反复强调，真正决定文章是否成立的是“标题—总论点—分论点”三层是否同题、同向、有材料来源。

## 二、第一步：判断单主题、双主题、多主题

拿到题目后先判断主题类型，再拟标题。

### 单主题

- 题干可以只出现一个核心词，也可以出现两个词。
- 如果两个词本质上是“对策—影响”关系，仍按单主题处理。例如“做好民生小事—成就国家大事”。
- 单主题的分论点最难找，因为题干往往不能直接给足三个角度，需要进入材料提炼。

### 双主题

- A、B 是相对独立且需要同时论证的两个对象，常见为并列、互补、对立统一或双向作用。
- 常见结构有 AB 类和 ABC 类：前者直接讨论 A 与 B 的关系；后者分别写 A、B 对共同目标 C 的作用，并说明二者协同。
- 标题、总论点和分论点都不能只写其中一方。

### 多主题

- 题干出现三个及以上关键词、短语或句子，并要求整体理解。
- 优先把题干中的多个主题直接转成分论点；如词义抽象或同音双关，要先依据所在材料解释。
- 若题干词语存在递进关系，分论点也应保持其顺序，而不是随意打散。

### 判断底线

主题数量不是机械数词。要先判断词语之间到底是“手段—结果”，还是彼此对等的多个主题。误判主题会继续传导到标题、总论点和整篇分论点。

## 三、标题与总论点

### 稳定结构

课程最常用的标题底层结构是：

> 对策/行动 + 影响/目标

例如，前半句回答“做什么、怎么做”，后半句回答“为了什么、产生什么结果”。题干只有问题时，可以将问题反推成对策；题干给出行动词时，优先保留原词并补足对象。

### 总论点

- 总论点本质上是把标题改写成完整句子，而不是另起炉灶。
- 总论点一般放在开头最后一句。
- 标题容纳不下的限定词、主题解释和共同目标，可以在总论点中补足。
- 文采化表达必须建立在题干关键词已经覆盖的基础上。

### 安全检查

拟完标题后反向检查：不看题干的人能否从标题大致猜出题目要求。如果完全看不出核心关键词，通常说明标题过空或发生偏题。

## 四、开头：四个组件

开头的稳定顺序是：

1. **名言警句或权威表达**：题干有原句时优先使用；没有时用与领域匹配的名言或背景句。
2. **影响/重要性**：说明主题为什么重要，可从政治、经济、文化、社会、生态或更具体的题目领域切入。
3. **过渡句**：连接背景与观点，可提前积累，但必须自然。
4. **总论点**：把标题改写成句子，并覆盖题干关键词。

个性化不是抛弃结构，而是在结构中替换更贴题的背景、问题、影响和表达。可在“名言—影响”之间加背景，或在影响后补问题，但不能让背景和名言挤占总论点。

## 五、分论点的寻找

### 来源优先级

1. 题干。
2. 题干引用句所在材料。
3. 全篇材料及前面的客观小题。

双主题和多主题通常优先从题干确定角度；单主题更常需要从材料寻找。客观小题可作为线索，是因为小题设问已经对材料做了主题压缩，但仍要回到原材料核验。

### 材料扫描顺序

1. 先找题干中的“动词 + 事情/对象”。
2. 看材料首段、尾段是否有总括性对策。
3. 看各段段首句、段尾句。
4. 看关联词、关键词、高频词和行动主体。
5. 仍找不齐时，逐句提取问题、原因、对策、影响，再选择层级最高、彼此不重复的主点。

课程在时间有限时优先找“对策型”分论点；影响可以随后补充。这个取舍是为了保证三个主体段先有清晰骨架。

## 六、分论点的润色

课程给出三种基本形式：

1. 总论点 + 分论点对策。
2. 总论点 + 分论点影响。
3. 总论点 + 分论点对策 + 分论点影响。

例如“推动农业高质量发展，要走质量兴农之路”属于第一种；若再补充该路径带来的结果，则成为第三种。

润色的目标是统一句式、保持长度接近、前置核心动词，并让三个分论点处于同一逻辑层级。两字、四字模板只能帮助组织语句，不能替代材料中真正的角度。

## 七、分论点论证

课程主要讲三类论证材料：

### 1. 要素论证

围绕分论点补写背景、问题、原因、对策、影响、目的、成绩等要素。优先改写材料，而不是凭空扩写。大作文因此可以理解成“把小题概括能力组合进段落”。

### 2. 事例论证

一个完整事例最多包含：

> 问题 + 主体 + 对策 + 影响

案例不必把四项全部写满，但必须保留能证明当前分论点的行动和结果。举例后最好做一句点评，说明案例中的对策和影响如何支撑观点。

### 3. 名言警句论证

可使用通用或领域化名言，但必须匹配论题。乡村治理案例不能直接当作行政执法创新的证据；如果只能证明“创新”这一抽象概念，就不要把它包装成特定领域的证明。

### 推荐段落顺序

> 分论点句 → 要素分析 → 材料/社会案例 → 案例点评 → 回扣分论点

这些组件可以按材料情况组合，不要求每段机械齐全。若影响难写，可用“主体分析法”分别考虑政府、企业、群众、个人等对象会得到什么改善。

## 八、结尾

结尾首先追求首尾呼应：开头使用的主题词、名言、影响和总论点，应在结尾以改写形式再次出现。

个性化结尾可以写：

> 与开头呼应的名言/背景 → 主题影响 → 回扣总论点及分论点 → 期待、呼吁或展望

时间紧张时可使用简化结构：

> 名言警句 → 影响或现实问题 → 展望号召

无论采用哪种形式，都不能在最后一段突然引入正文从未讨论的新主题。

## 九、整套方法的考场执行清单

1. 圈出题干关键词、限定领域和关系词。
2. 判断单、双、多主题，并写出各主题之间的关系。
3. 用“对策 + 影响”拟标题，再把标题改写成总论点。
4. 按“题干 → 所在材料 → 全篇/小题”寻找三至四个分论点。
5. 把分论点统一成“总论点 + 对策/影响”的平行句式。
6. 每段至少准备一种要素分析和一项材料证据；案例必须与领域匹配。
7. 用四组件完成开头，用首尾呼应完成结尾。
8. 最后检查标题、总论点、分论点是否都覆盖题干关键词，分论点之间是否重复。

## 十、转化为 AI 大作文教练时的建议

课程内容适合转化为以下可解释规则：

- **主题分类器**：输出单/双/多主题、关键词和关系，不只给标签。
- **标题检查器**：检查题干关键词覆盖、对策和影响是否完整、是否空泛。
- **总论点一致性**：比较标题与开头末句是否同义，发现另起观点。
- **分论点溯源**：每个分论点必须标注来自题干、所在材料、全篇材料或客观小题的证据。
- **层级与重复检查**：识别三个分论点是否同层、是否语义重合、是否漏掉双/多主题中的一项。
- **段落组件标注**：识别分论点、要素分析、案例、点评和回扣，指出缺失但不强迫模板齐全。
- **案例匹配检查**：判断案例能否证明当前领域和具体观点，而不只是共享一个抽象词。
- **首尾呼应检查**：比较开头、结尾与总论点的主题覆盖，防止结尾跑出新主题。

需要谨慎的是：这套资料主要是写作教学证据，不是正式阅卷评分细则。可以据此训练结构诊断和修改建议，但不宜把课堂中的宣传性分数判断直接写成硬性评分规则。
