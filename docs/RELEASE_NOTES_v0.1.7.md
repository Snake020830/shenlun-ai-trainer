# 申论训练助手 v0.1.7

## 这是什么软件

申论训练助手是一款本地优先的申论训练工作台：题库、材料阅读、草稿、训练记录和批改快照保存在本机，适合把“独立作答—提交批改—错题复盘”串成持续训练闭环。

主要功能包括：

- 近年公开申论整卷发现、结构校验和题目导入；
- 材料阅读、高亮/下划线/批注和来源追溯；
- 概括归纳、提出对策、综合分析、贯彻执行等题型训练；
- 大作文独立五步短练、整篇作答和五维度批改；
- 草稿自动保存、进行中答题、训练记录和错题复盘；
- 可选的远程 AI 批改，模型凭据保存在操作系统凭据库。

## 本次更新

- 修复桌面版启动时偶发的 SQLite 初始化或迁移时序异常。应用现在会自动重试 3 次，等待间隔为 0.5 秒、1.5 秒和 3 秒，共最多尝试 4 次。
- 启动重试期间不会创建空的 localStorage 数据，也不会删除或覆盖已有题库、草稿、训练记录和批改快照。
- 只有连续重试仍然失败时，才会进入数据保护页面，提示用户检查本地数据，而不是把空数据误显示成“数据丢失”。
- 版本号更新为 `0.1.7`。

## 数据安全提醒

升级或安装前请不要卸载应用、清空应用数据或删除数据库目录。正式版数据目录为：

`%APPDATA%\\com.shenlun.trainer`

本版本不删除已有题库、草稿、训练记录或批改快照。若启动时数据库暂时不可用，应用会先自动重试；数据保护页面仅表示重试后仍未能安全打开本地数据。
